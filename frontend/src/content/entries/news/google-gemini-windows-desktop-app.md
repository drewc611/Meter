Google shipped a native Gemini desktop app for Windows on September 10, 2026, available globally for Windows 10 and 11 on both x64 and ARM64. Alt+Space summons Gemini over whatever window is currently active. The app bundles Gemini Spark -- an always-on personal agent with access to connected apps -- alongside Nano Banana image generation, Gemini-powered video generation, and a side panel for Notebooks and recent activity.

## System-level, not a tab

Google's own pitch for the everyday use case: help people "polish drafts, summarize long documents, brainstorm new ideas" without switching to a browser. Putting Gemini on the same Alt+Space-style footing as Windows' own search puts it in direct daily competition with Microsoft's own Copilot, on Microsoft's own operating system -- a more aggressive distribution move than a browser extension or a standalone app most users have to remember to open.

## The measurement question this raises

A system-level assistant that's always one keystroke away is exactly the kind of tool where "who's actually using this, and is it displacing real work" becomes hard to answer from adoption numbers alone -- the same measurement problem this site's own scoring model exists to address, just moved from a specific coding tool to a general-purpose OS utility.
