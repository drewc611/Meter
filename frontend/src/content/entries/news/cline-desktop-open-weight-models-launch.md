Cline, previously known as a VS Code extension for autonomous coding, announced Cline Desktop on September 14 -- a standalone native app that drops the code-editor dependency entirely. The company's own blog post pitches it as letting developers "run parallel AI agents, automate recurring tasks, choose from 300+ models" and extend the workflow with plugins, MCP servers and skills, alongside scheduled runs for recurring jobs like morning PR reviews or nightly security scans, and the ability to import in-progress tasks from Claude Code or Codex.

## Free models, and the pass behind them

Cline's own announcement on X frames the model access directly: "Introducing Cline Desktop -- a native interface for working with open weights models," usable "with ClinePass and all our free models like DeepSeek-V4.1-Flash, Musespark-1.3, or BYOK with any provider." ClinePass is Cline's existing subscription for discounted access to open-weight models -- the company has separately said it offers roughly 5x-discounted usage versus paying providers directly -- and Desktop is built to work with it out of the box rather than requiring a connected API key.

## The open-weight bet

The framing matters for a coding-agent market that has mostly competed on proprietary frontier models: Cline is explicitly betting that a large share of coding-agent usage doesn't need GPT- or Claude-tier reasoning, and that a native app tuned for cheaper, open-weight models is worth building as its own product rather than a fallback mode. Whether that bet pays off in practice is a question about routing and output quality per dollar -- exactly the kind of tool-level cost/value split Merit AC's tool-breakdown analytics are built to surface once usage data exists to measure it.
