Anthropic added smart reports to Claude Enterprise in beta on September 10, 2026, per its own release notes. The feature analyzes how a team uses Claude -- work completed, cost, where sessions hit friction -- and surfaces repeated patterns worth turning into shared, reusable Skills, all inside the product rather than through a separate analytics tool.

## Anthropic's own description of what it does

The release notes describe the feature as built to "analyze how a team uses Claude and report on the work getting done" -- cost and output, read together, inside the vendor's own product, for Enterprise-plan customers in beta.

## A vendor building the exact category this site tracks

This is Anthropic shipping a first-party version of spend-plus-output visibility -- the same combination Merit AC's own scoring model is built around, just scoped to one vendor's own product rather than an organization's full AI tool stack. For any company already paying for Claude Enterprise, it's a real, free-with-the-plan alternative worth weighing against a third-party tracker; for anyone running AI spend across multiple vendors, it's a reminder that single-vendor usage analytics will always miss the cross-tool picture a platform-agnostic tracker exists to provide.
