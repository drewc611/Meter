Replit's autonomous coding agent, bundled into Replit's browser-based IDE rather than sold as a separate product. It builds, debugs, and deploys full apps from a prompt; usage is billed under "effort-based pricing" that scales cost with task complexity, drawing down each plan's included model credits before switching to pay-as-you-go.
