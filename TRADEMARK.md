## Using the ™ mark

Until (if) a registration issues, use the "TM" superscript — not the
registered "®" symbol, which is reserved for marks the USPTO has actually
registered and can expose you to misuse claims if used prematurely.
`frontend/index.html` and the root `README.md` mark the name at first,
prominent use per page; it doesn't need to be repeated on every mention.
