# What you can do with Merit AC's code

Plain writing, before you rely on it. The formal version is in `LICENSE` and
says the same things in the language a court reads. If the two ever
disagree, that is a mistake and this file is what was meant. (Operator OS
has its own separate license and its own plain version --
`operator-os/LICENCE-PLAIN.md` -- this file is about Merit AC only:
`backend/` and `frontend/`.)

## Free: your own personal use

You can read this code, run it, and modify it for yourself, free, as long
as you're an individual using it for your own purposes -- for example,
self-hosting it to track your own AI spend. That stays free no matter how
you modify it, as long as it stays personal: not on behalf of a company,
not to make money, and not handed off to anyone else.

## Not free: anything on behalf of an organization

The moment this code is doing something for a company or other
organization -- internal use, a paid or unpaid service to others,
evaluating it for a purchase decision -- that's commercial use, and it
needs a separate written license from us first. That includes running your
own hosted copy for your team. Reach out before you put it to that use.

## What you can't do either way

Redistributing, sublicensing, or selling the code or a derivative of it
isn't included in either grant above. Neither is representing a modified
or hosted version of it as your own separate product.

## The hosted product at usemeritai.com

Using the live dashboard is separate from this code license entirely --
that's covered by whatever's stated at signup, plus the terms on
[/pricing](https://usemeritai.com/pricing) for a paid consultation or
subscription. This file is about the source code in this repository, not
about using the hosted service.

## Warranty, honestly

The software is provided as-is. We're not promising it's bug-free, that
its numbers are complete, or that it fits a particular purpose -- see the
full disclaimer in `LICENSE`. This early prototype label on the dashboard
means what it says: verify anything that matters against your own systems
before acting on it.
