# 07 Boundaries

What this system will not do, so you never have to wonder.

## It never sends anything

Every message the tools produce is a draft. Invoices, chases, follow ups,
content. You send them. The relationship is yours and so is the send button.

## It never deletes a row

Statuses exist for this: `dropped`, `lost`, `cancelled`, `written_off`,
`expired`. The history stays. `reaper` changes state, it does not remove.

## It never contacts anyone marked do_not_contact

Every tool honours that status without exception and without asking.

## It never leaves your machine

No account, no server, no telemetry, no sync. `data/` is a folder on your disk.
If you put the repo in a cloud drive, that is your choice and your risk.

## It never gives professional advice

Tax, legal, employment, insurance. The tools give you organised facts about your
own business and tell you to take them to a professional. `taxset` says this out
loud every single time it runs, on purpose.

## It never invents a number

Every figure it reports comes from `lib/` arithmetic over rows you can open. If
an assistant using these tools ever states a number you cannot find in a file,
that is a defect, not a feature.

## It never marks its own homework

Each tool ends with a finish line you check yourself. "Done" is not a claim the
tool gets to make.

## What you should still do yourself

Back up `data/`. Read the recurring cost list out loud monthly. Decide your own
prices. Answer your own phone.
