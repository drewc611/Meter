# The Workbook

Nine modules. About seven and a half hours in total, and you can stop after any
of them with something working. Nothing here depends on a live session, a video,
or anyone being awake at the same time as you.

## How to read a module

Every module has the same five parts.

1. **The finish line.** What is true when you are done. Written first so you can
   check whether it is worth your hour.
2. **Do this.** Numbered commands. Mac in one block, Windows in another. Never
   both mixed together.
3. **Say this.** The exact words to give your assistant, in a copyable block.
   Not a paraphrase of what to ask for. The words.
4. **Check it.** A command whose output proves the module worked.
5. **When it goes wrong.** The three failures that actually happen, and the fix.

## Two conventions

Commands are written for the Mac as `./os something` and for Windows as
`.\os.cmd something`. After module 01 both platforms can just type `os something`
from anywhere.

Anything in a block like this is meant to be pasted to your assistant verbatim:

```
Run the chase tool. Work the aging report top down and draft one message per
overdue invoice in my voice. Do not send anything.
```
