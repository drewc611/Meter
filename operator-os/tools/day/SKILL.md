# day

Five minutes. Same order every time. The value is the repetition, not the
cleverness.

## Reads

`os brief`, `os aging` when money is late, `os capacity` on a Monday.

## The run

1. Run `os brief`. Read it out in this order: cash low point, money late,
   overdue, due today, deals waiting.
2. Pick three. Not five. One that protects money, one that moves committed work,
   one that keeps next month alive. If all three cannot be named, the list is
   noise and the day starts with `reaper` instead.
3. Anything overdue by more than a week gets a decision, not a reschedule.
   Reschedule it, delegate it, or drop it. A third rescheduling is a drop that
   nobody admitted to.
4. Say the one thing that must be true by tonight. One sentence. That is the
   finish line for the day.
5. Stop. Do not plan the week here. The `schedule` tool does that once, on
   Monday.

## Writes

Sets `priority=now` on the three chosen tasks. Nothing else.

## Finish line

Three task ids and one sentence. If it took longer than five minutes, the tool
was used wrong.

## Refuses

- To produce a list longer than three.
- To reschedule the same task a third time without asking whether it should
  exist.
